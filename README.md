# Manim Studio

<img src="icon.png" alt="" width="64" align="right">

*Formerly MathEngine: the `mathengine` command and `.mathengine` projects still work.*

A drag-and-drop editor for [manim](https://www.manim.community/) (Community Edition) videos. Build scenes
on a Premiere-style timeline, edit any argument as Python, and export a real manim `.py` file or MP4.
The timeline and the code are the same thing: paste a manim scene and it becomes clips; edit the timeline
and the code changes with it.

The GUI is generated by introspecting manim itself: every `Mobject` and `Animation` class appears in the
library with its real constructor signature. Previews are drawn by manim's own renderer and exports run
the `manim` CLI.

## Features

- **Timeline**: `construct()` as a timeline. Each statement (`self.play`, `self.wait`, `self.add`, code) runs
  after the one before it; the animations of a `self.play` stack on tracks below it. Drag, trim `run_time`,
  ripple delete, snap, multi-select.
- **Code**: the scene as editable manim code, in sync both ways. Paste or open a whole manim file and its
  scene becomes the project; anything it can't model is kept as a code step.
- **Library**: drag any manim class onto the canvas or a track.
- **Inspector**: a control for every parameter, chosen from its manim signature (pickers, sliders, lists,
  grids), with a `{}` toggle to type raw Python.
- **Visual construction**: drawing tools, connected geometry (intersections, perpendiculars, labels, angle
  marks) that stays correct as you edit, a `y = a*x^2 + b` graph builder with parameter sliders, equation
  term editing, and reusable constructions.
- **Help**: `?` or `F1` opens a searchable guide and an interactive tour.

## Download

Builds for Windows, macOS (Apple Silicon and Intel) and Linux are on the **Releases** page. They include
Python, manim and ffmpeg, but not LaTeX (needed only for equations). The `-cli` executable renders from a
terminal.

- **Stable** releases (`v0.2.0`, …) are the ones to use. The app notifies you of newer ones (disable in
  Settings or with `MATHENGINE_NO_UPDATE_CHECK=1`).
- **Nightly** is rebuilt from every push to `main` and may be unfinished.

To release: set `version` in `pyproject.toml`, commit, then `git tag v0.2.0 && git push origin v0.2.0`
(`.github/workflows/release.yml`). To build locally:

```bash
pip install . pyinstaller              # on Linux also: pip install "pywebview[qt]"
cd packaging && pyinstaller manim-studio.spec   # -> packaging/dist/
```

## Install from source

```bash
uv venv --python 3.12 && uv pip install -e .     # or: pip install -e .
cd frontend && npm install && npm run build        # builds the UI into mathengine/web
```

Requires manim 0.22 or newer. **LaTeX** (MacTeX/BasicTeX, TeX Live, MiKTeX) is needed for equations
(`MathTex`, `Tex`). Without it, numbers and simple labels fall back to `Text` and everything else works.
ffmpeg comes with manim via PyAV.

## Usage

```bash
manim-studio                                # open the editor
manim-studio examples/sine_tracker.manimstudio
manim-studio --browser                      # use your browser instead of a native window
manim-studio scene.py                       # open a manim file as a timeline
manim-studio render scene.manimstudio -q 1080p -o scene.mp4   # headless render
manim-studio code scene.manimstudio > scene.py                # export plain manim code
manim-studio import scene.py -s MyScene -o scene.manimstudio  # convert a file to a project
```

Shortcuts: Space play · J/K/L · ←/→ frame · M marker · S snap · Del / ⇧Del ripple delete · ⌘Z/⇧⌘Z ·
⌘S · ⌘D duplicate · 1–7 drawing tools · ? or F1 help.

## How it works

```
frontend/ (React)  ──HTTP (127.0.0.1 + session token)──▶  mathengine/server.py
                                                            ├─ catalog.py    introspects manim → palette & forms
                                                            ├─ codegen.py    document → manim Python
                                                            ├─ importer.py   manim Python → document
                                                            ├─ timeline.py   the timeline's statements
                                                            ├─ construct.py  linked objects, equation terms
                                                            ├─ mathexpr.py   math expressions → Python
                                                            ├─ starters.py   built-in constructions
                                                            ├─ runtime.py    seek to time t, render one frame
                                                            └─ render.py     `manim render` for video
```

A project (`.manimstudio`) is JSON: objects plus the list of `construct()` statements. Every argument is
stored as Python source, so anything manim accepts is representable. Each statement compiles to exactly one
manim statement, and the importer reads code back with `ast`, so code → project → code is stable and an
imported scene runs exactly like the original. Connections between objects compile to plain manim code via a
small `Constraints` helper emitted into the file. Previews re-run `construct()`, skipping animations up to
the requested time, and draw that moment with the scene's camera (about 50–150 ms per frame).

## Development

```bash
cd frontend && npm run dev                  # rebuild the UI on change
manim-studio --serve --port 8765            # server only
uv pip install -e '.[dev]' && pytest        # tests render real frames; LaTeX tests skip without LaTeX
```

`scripts/verify_controls.py` checks every parameter control against manim (rerun after upgrading manim);
`scripts/ui_smoke.py` drives the editor in Chromium via Playwright. Design notes:
[`docs/research/math-object-creation.md`](docs/research/math-object-creation.md).
